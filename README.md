# 安安糖果手绘

独立的糖果纸手绘主题开发仓库，基于 [安安打字操作 2.1.0](https://github.com/aaaa0718/anan-typing-pet/releases/tag/v2.1.0-preview) 的交互代码起步。

**当前是开发基线，画面仍为原版水彩角色，糖果主题尚未实现。** 不影响原仓库版本。

方向：蜡笔颗粒、手绘边缘、草莓粉/正红/天蓝/奶油黄配色；保留女孩身份、透明桌面背景与原有交互。先制作糖果服装与配套键鼠，再考虑统一跳字标签和换装入口。具体造型须经用户预览确认。

`python3 source/build.py` 构建 `dist/安安糖果手绘.app`。需要 macOS、Xcode Command Line Tools 与 Python 3。使用独立应用标识与设置域，与原版隔离。

素材基于用户参考的 AI 辅助创作；暂未指定开源许可证。
